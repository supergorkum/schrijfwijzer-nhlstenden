# Schrijfwijzer NHL Stenden

Een tool die documenten (Word, PDF of tekst) automatisch aanpast aan de
schrijfregels, tone of voice en huisstijl van NHL Stenden Hogeschool.

Status: eerste opzet. Upload, vragen en resultaat zijn nu nog lege stappen,
in latere patches komt hier de daadwerkelijke logica in.

## Ontwikkelen

```
npm install
npm run dev
```
